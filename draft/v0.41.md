## 实现方案

### 转换目标

```tsx
// 输入
ref: let a = 1;
ref: let b = 2;
computed: let c = a + b;

function Component() {
  // ...
  return <div>
          <div>value of a:{a}</div>
          {c + 3}
    </div>
}
```
转化为
```tsx
import { ref, computed } from '@ktjs/core';

const a = ref(1);
const b = ref(2);
const c = computed(() => a.value + b.value, [a, b]);

function Component() {
  // ...
  return <div>
          <div>value of a:{a}</div>
          {computed(()=>c.value+3,[c])}
    </div>;
}
```
因为kt.js对{}中为reactive的值是会自己处理的，所以`<div>value of a:{a}</div>`前后不变；
但是`{c + 3}`中c是reactive的，所以需要改成`{computed(()=>c.value+3,[c])}`。
