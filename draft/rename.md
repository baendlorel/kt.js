> 目标：给框架改名时，先从常见的 VOICEROID / A.I.VOICE / VOICEVOX / VOICEPEAK / CeVIO AI 角色里挑。
>
> 说明：
> - 这里优先收录“常见、辨识度高、社区里常被提到”的名字，不追求绝对穷尽。
> - 罗马音以常见 Hepburn / 官方常用写法为主；`KAFU`、`OИE`、`ROSA`、`#kzn`、`WhiteCUL`、`Ci flower` 等保留惯用官方写法。
> - 我**没有**顺手检查 npm 是否已占用，这份先只当名字池。

## 6. 个人觉得更适合拿来做框架名的一批

这些名字的共同点是：
- 发音清楚
- 拉丁字母拼写长度中等
- 不像 `kotlin`, `react`, `vite` 这种已被技术圈强绑定
- 比 `yukari`、`akari`、`zundamon` 这类超热门名略微没那么撞

### 比较顺口

- `unoka`
- `tobari`
- `kotone`
- `seika`
- `metan`
- `tsudumi`
- `sasara`
- `moca`
- `coko`
- `haru`
- `koto`
- `hano`
- `sayo`
- `sorin`
- `hanamaru`

### 更像“框架名”而不是“角色本名”

- `voidoll`
- `whitecul`
- `frimomen`
- `popy`
- `rose`
- `rimuru`
- `laika`
- `galaco`
- `kafu`
- `sekai`
- `rime`

### 如果你想走“和风 + 柔和 + 好记”

- `sasara`
- `tsudumi`
- `seika`
- `kotone`
- `unoka`
- `sayo`
- `hano`
- `koto`

### 如果你想走“短、硬、偏工具味”

- `kafu`
- `rime`
- `coko`
- `haru`
- `rose`
- `popy`
- `moca`
- `laika`
